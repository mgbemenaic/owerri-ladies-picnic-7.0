# Owerri Ladies Picnic 7.0 Website

This is a static, GitHub Pages-ready website.

## Deploy with GitHub Pages

1. Create a new GitHub repository.
2. Upload **all files in this folder** to the repository root. Keep the main page named `index.html`.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then click **Save**.
6. Wait for GitHub Pages to publish the site. The public URL will appear in the Pages settings.

## Notes

- The page is self-contained; its carousel images are embedded in the HTML.
- Google Fonts are loaded from Google Fonts when visitors have an internet connection. System font fallbacks are included.
- WhatsApp, Instagram and TikTok links require internet access.
- No Node.js build step or package installation is required.
