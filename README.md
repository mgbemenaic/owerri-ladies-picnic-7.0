# Owerri Ladies Picnic 7.0

A static, single-file website ready for GitHub Pages.

## Deploy with GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html` to the repository root (the top level, not inside a folder).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your branch (usually `main`) and folder `/(root)`, then save.
6. Wait for GitHub Pages to publish the site; the URL will appear in the Pages settings.

All 57 photographs are embedded directly in `index.html` as Base64 data. No image folder or additional asset files are required.
