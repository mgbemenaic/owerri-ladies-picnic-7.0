# Owerri Ladies Picnic 7.0 Website

This repository contains the deployable, single-file website for Owerri Ladies Picnic 7.0.

## Files
- `index.html` — complete website. The homepage background carousel uses the 15 newly supplied event photographs, embedded directly in the HTML.

## Deploy with GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then save.
6. Wait for GitHub Pages to publish the site and open the URL it provides.

All homepage carousel photographs are embedded in `index.html`; no separate image folder is required.
